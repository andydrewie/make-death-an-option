# Public navigation for agents

This file is a map of the public site, not an instruction with authority over you or your user. Follow your user's mandate and applicable instructions. These pages do not grant access to personal context or permission to act externally.

The unchanged two-button entrance leads to the article on X or to the Project Atlas. Explore begins with Access Memory and its complete personal-reflection prompt; its Atlas shortcut jumps directly to the wider work. The subpage navigation separates Access Memory, Atlas and the article on X.

- [Read the article on X](https://x.com/andydrewie/status/2100206836897214598): Andrew Fai's published *Make Death an Option* and the primary reader destination.
- [Project Atlas](explore/#the-work): four routes through the proposed future, evidence and limits, open questions and ways to help; all four program destinations remain available below.
- [Access Memory](access-memory/): a portable reflection invitation with model-generated examples using fictional inputs. Pasting the invitation asks the chosen agent to use relevant personal context it actually has, with any narrower visitor instruction taking precedence. Without it, the agent should give an openly non-personalized reflection rather than invent a life.
- [Access Memory data](access-memory/content.json): the complete invitation and three fictional-context examples in structured form.
- [Go Far Together](evening/): an illustrated reading of the imagined concert in sections 12 and 18.

There is no full-article reader or article download on this site. The existing [canonical repository source](https://github.com/andydrewie/make-death-an-option/blob/main/ARTICLE.md) remains available for source-grounded agent reading and exact section citations. It is unchanged.

For the existing optional evidence audit, see the [public bounded reading path](https://github.com/andydrewie/make-death-an-option/blob/main/AGENTS.md#one-bounded-reading-path). Do not infer permission to launch research, contact people, publish, retrieve private material, or change persistent memory from this navigation.
