# Source navigation and checking limits

This index links the public material used by the four bounded assessments. Source identification, access, targeted checking and independent replication are different states. A source link is not an assertion that every method or later correction was reviewed. Original checking occurred in September 2026; the memory/biology locator-only follow-up on 17 September verified bibliographic identity without repeating the scientific assessment.

Detailed claim mappings: [memory and biology](research/source-index-memory-biology.json), [identity and alignment](research/source-index-identity-alignment.json). They preserve source versions, access limits and checking scope. These indexes contain citations and assessment metadata, not source bodies.
